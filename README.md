# JavaScriptFundamentos03.1

Continuação dos estudos de JavaScript com foco em funções, metodos de array, objetos , JSON e introdução a Programação Orientada a Objetos.

## Objetos

Ao final deste projeto, o aluno devera ser capaz de:

- Criar e utilizar funções;
- Trabalhar com parametros, argumentos e retornos;
- Utilizar Arrow Functions;
- Criar e manipular objetos;
- Trabalhar com arrau de objetos;
- Entender o uso de `this`;
